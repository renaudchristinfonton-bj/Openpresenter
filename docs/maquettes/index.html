Comment lire ces maquettes

  • Les libellés sont définitifs : ce sont les chaînes à implémenter.
  • Les états (live, vide, erreur, désactivé) sont représentés à côté de leur description.
  • Chaque page indique le chapitre de docs/spec/ dont elle dépend.
  • Une maquette n'est pas une proposition de style : la direction visuelle reste à définir.
