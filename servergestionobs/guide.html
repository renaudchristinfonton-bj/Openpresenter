🎛️ Guide de démarrage OpenPresenter

De l'installation au culte de dimanche — en 10 minutes. Tout se passe sur votre réseau local : aucune connexion Internet n'est nécessaire après le premier lancement, et vos données restent dans le dossier du projet.

1Installation (une seule fois)

1
Installez Node.js (version LTS) depuis nodejs.org — c'est le petit moteur qui fait tourner le serveur.
2
Double-cliquez sur demarrer-windows.bat (ou demarrer-mac-linux.command). Le navigateur s'ouvre tout seul sur la page d'accueil.
3
Si Windows demande d'autoriser Node.js sur le réseau privé : acceptez (c'est ce qui permet aux autres appareils de se connecter).
Astuce : pour découvrir OpenPresenter sans rien saisir, cliquez « 🧪 Installer le contenu de démo » sur la page d'accueil (2 chants avec accords, un look, une trame du temps, un plan de culte).

2Branchez OBS (5 minutes)

1
Dans OBS : Sources → + → Navigateur. Copiez-y le lien « Lien général » de l'outil (bouton Copier dans chaque outil).
2
Réglez la Source Navigateur en 1920 × 1080 (ou la taille exacte choisie dans le panneau « Résolution de sortie »).
3
Encore plus simple : bouton « 🎬 Installer les scènes OBS » de la page d'accueil (crée tout automatiquement si obs-websocket est activé).

3Checklist du dimanche matin

✓
Lancer demarrer-windows.bat → le navigateur s'ouvre. Laissez la fenêtre noire ouverte.
✓
Régie : ouvrir le Studio Unifié (tout-en-un) — champ « 🔍 Tout chercher » pour trouver un chant/verset/média et Entrée pour diffuser.
✓
Ouvrir la Régie Pasteur sur un 2ᵉ écran : file de décomptes (ordonnables à la souris) + envoi de messages.
✓
Écran du pasteur : vue_pasteur.html sur sa tablette/TV (3/5 diffusion · 1/5 minuteur · 1/5 messages). Écran des musiciens : stage_display.html.
✓
Habillage : carte 🎨 Looks de l'accueil — un clic change Bible + Paroles.
✓
Fin de culte : bouton « ⬇️ Sauvegarder tout » de l'accueil → un seul fichier avec tout.

5Problèmes fréquents

Le badge dit « Local uniquement » — la page a été ouverte en double-clic. Ouvrez-la via http://localhost:8787/… (le serveur doit tourner).

Un autre PC ne se connecte pas — utilisez l'adresse « Depuis le réseau » affichée au démarrage ; vérifiez que les deux appareils sont sur le même WiFi et que le pare-feu autorise Node.js (réseau privé).

Le port 8787 est pris — un serveur tourne déjà (utilisez-le) ou lancez avec un autre port : set PORT=9000 puis le .bat.

Une page reste vide — appuyez sur F5 ; si un bandeau rouge « Erreur… » apparaît, notez le message : il dit exactement quoi signaler.

OpenPresenter — 100 % local, sans abonnement. Tout ce qui est dans le dossier du projet (médias, chants, réglages, looks) voyage avec lui : copiez le dossier, et la régie suit.
