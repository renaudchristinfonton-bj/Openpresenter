Crée automatiquement les Sources Navigateur (Bible, Paroles, Médias, Titres) et les scènes de présentation dans OBS. Prérequis : activez obs-websocket dans OBS (Outils > WebSocket Server Settings, noter le port 4455 et le mot de passe).

Sauvegardez tout d'un coup (versets favoris, chants, médias, présents, file de déroulement, réglages, groupes) dans un seul fichier, et restaurez-le sur cet ordinateur ou un autre.
